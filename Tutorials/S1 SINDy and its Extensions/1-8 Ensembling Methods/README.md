# Ensembling Methods

In machine learning, ensembling is the combination of multiple models to produce a more robust output. In this tutorial, we will cover two separate uses of ensembling:
* 1-8-1 Ensemble SINDy: Apply ensembling to mitigate effects of noise, and quantify both model and output uncertainty.
* 1-8-2 Active SINDy: Apply ensemble models to actively guide the data sampling and model learning process.
